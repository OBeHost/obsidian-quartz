# Referate & Inputs 
Unten findest du eine Tabelle mit verschiedenen Spalten. Hier eine Erklärung dafür, was in diese Spalten geschrieben werden sollte sowie das Format in welchem es geschrieben werden sollte: 
- Datum: 
	- dd.mm.yy
- Genosse:
	- Kürzel des Genossen welcher das Referat hält
- Thema:
	- Thema als Titel angeben
- Handout:
	- Wenn es ein Handout gibt, dieses hier verlinken
- Link zu OG Note
	- Immer die OG Note von der Sitzung in welcher das Referat gehalten wird verlinken.
	- Falls noch keine OG Note existiert, kannst du einen Link für eine neue Note erstellen
	- Benennung OG Note: "OG \{dd.mm.yy\}"
- Ressourcen:
	- Verlinke hier jegliche Ressourcen die für das Referat relevant sind
	- Das können Links zu Notes im Vault sein, sowie externe Links 

Wenn du eine Idee für ein Referat hast, kannst du dieses Thema sowie den Kürzel des Genossen in eine Zeile schreiben, auch wenn das Datum noch nicht klar ist. Um Zeilen zu verschieben, gehe mit dem Mauszeiger ganz links zur Zeile, bis eine Greifhand erscheint. Ziehe dann die Zeile an den gewünschten Ort. Beachte, dass die Zeilen nach Datum sortiert sein sollten.
